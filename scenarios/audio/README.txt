Pre-recorded messages
=====================

Scenario columns passenger_message, passenger_reply and external_reply may
name a file in this folder instead of containing the text itself.

  * An audio file (.wav, .ogg, .mp3, .flac) is PLAYED.  If a .txt file with
    the same name exists, its text is shown on screen as a transcript.
  * A .txt file is SHOWN as text.

The .txt files here are placeholders that describe what each recording
should say.  To use a real recording, add e.g. "I feel carsick.wav" next to
"I feel carsick.txt" and change the scenario cell to "I feel carsick.wav".
